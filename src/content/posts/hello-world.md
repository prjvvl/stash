You don't need to touch any HTML, CSS, or JavaScript to add a page like this one.

Add a new `.md` file to `src/content/posts/`, fill in the frontmatter at the top
(title, description, date, tags), and write the rest as normal Markdown. The
build validates your frontmatter automatically — if a required field is
missing or the wrong type, you'll get a clear error instead of a broken page.

## Adding your own content

1. Copy this file.
2. Rename it and update the frontmatter.
3. Replace this text with your own.
4. Push — the site rebuilds and deploys on its own.
